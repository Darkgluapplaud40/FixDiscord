Если вы хорошо понимаете настройку исключений, предпочтительно создать исключение; при отсутствии уверенности лучше отключить обнаружение PUA.

## ⚙️Использование

1. Сначала активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличного от варианта "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдет `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокированным
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 это рекомендуемый вариант
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При распаковке через 7-Zip или PeaZip данный пункт можно не выполнять

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Откройте нужный скрипт
    * Для поиска работающей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления в автозапуск: **`service.bat`** -> `Install Service` -> *Выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо запустить заново.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — переключение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret доступен, а с ним не работает  
  В скобках показывается один из статусов:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяются IP, входящие в список
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручной поиск обновлений
  - **`Run Diagnostics`** — проверка распространённых причин, из-за которых zapret может не запускаться или не работать.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; иногда это возвращает работоспособность клиента
  - **`Run Tests`** — запуск проверки стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, отвечающий за обход; его можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните по очереди следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте всё содержимое открывшегося блокнота
  - Через текстовый редактор, запущенный от имени администратора, откройте файл `hosts` в созданной папке
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните изменения и проверьте соединение. Если результата нет, убедитесь, что файл `hosts` действительно был сохранён.

#### Работа не гарантирована. Если этот способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Darkgluapplaud40/tg-ws-proxy) либо с любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Со временем стратегии могут терять работоспособность.**
> Конкретная стратегия способна работать некоторое время, а затем перестать работать после её обнаружения.
> Здесь доступно много разных стратегий обхода. Если ни одна не подходит, создайте новую на основе одной из имеющихся и измените её параметры.
> Описание параметров стратегий приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что нужный адрес присутствует в списках доменов или IP

- Переключитесь на другие стратегии (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Скопируйте добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если будут ошибки, исправьте их, затем в конце выберите Y
- Удалите старый каталог с zapret
- Возьмите свежую версию на [странице релизов](https://github.com/Darkgluapplaud40/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву и откройте свойства. Если внизу справа доступен пункт разблокировки, установите его, нажмите применить и затем ОК
- Распакуйте архив в новую папку в корне диска; путь не должен включать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте сайты. Если доступ отсутствует, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе могут заблокироваться ресурсы, которые вы не планировали фильтровать.

### Античит ругается на WinDivert

- Изучите инструкцию по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Получите имя службы командой в Windows через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал против них активно бороться.
- Испытайте остальные стратегии, особенно если раньше всё работало.
- Дополнительно см. [#251](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, можно временно пользоваться ей.
- Когда Discord не открывается и в браузере, снова проверьте все стратегии: иногда YouTube работает на одной, а Discord — на другой.
- Дополнительные сведения: [#252](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Darkgluapplaud40/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси, доступными в интернете

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Для начала используйте универсальную последовательность:
- в `service.bat` обновите ipset и включите `Game Filter`
- если это не решит проблему, дополнительно включите `ipset any`

Учитывайте, что режим `ipset any` может нарушить доступ ко многим сайтам. Не оставляйте его включённым постоянно: определите IP-адреса, используемые игрой, и добавьте их в `ipset-all.txt`

Если результата нет, создайте обсуждение в разделе [Discussions](https://github.com/Darkgluapplaud40/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/Darkgluapplaud40/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода можно указывать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не требуется
- **`ipset-all.txt`** — отдельные IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
